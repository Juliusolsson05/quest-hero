# TrueForge UI SDK

> Use the bundled TrueForge chat experience — or embed the same UI in your app with the React UI SDK.

`@truefoundry/trueforge-ui` provides a production-ready agent chat experience as a single, reusable React component. TrueForge ships this full chat UI with the server — browse agents, stream responses, approve tools, connect MCP OAuth, and manage Settings — and publishes the same experience as `@truefoundry/trueforge-ui` so you can embed it in your own React app.

Key Features:

* **Agent Modes** - Chat with a single agent, browse an agent library, or allow users to create and compose new agents.
* **Chat** - Supports streaming responses, session history, tool calls with approval workflows, and file attachments.
* **Themes** - Includes built-in themes for Claude, ChatGPT, Gemini, and TrueFoundry, with support for creating custom themes.
* **Layouts** - Supports full-screen layouts with a sidebar or drawer, as well as embedded layouts with side-docked or floating widgets.
* **Integration Settings** - Configure models, MCP servers, skills, and sandbox environments.
* **Server Configuration** - Choose between TrueForge, a fully custom server, or TrueFoundry.
